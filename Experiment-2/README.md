# Experiment 2 — Task Manager

This Vite/React exercise builds a task-management interface with add-task, list/item components, profile and statistics panels, and context/reducer-based state.

From this directory:

```bash
npm ci
npm run dev
```

Use `npm run build` to create the production bundle and `npm run lint` to run the configured linter. This exercise is independent of `Experiment-3`; see the repository-level README for both projects. No backend is included.
