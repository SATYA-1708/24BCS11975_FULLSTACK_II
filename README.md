# Full Stack Development Coursework

A coursework repository containing two separate React/Vite experiments. They are independent applications with their own package manifests.

## Experiment 2

A task-management interface with task creation, list and item components, context/reducer state, and task statistics.

## Experiment 3

A separate React application using React Router. Its files and dependencies are isolated from Experiment 2.

## Run either experiment

Choose one folder and run its scripts there:

```bash
cd Experiment-2
npm ci
npm run dev
```

For the second exercise, substitute `Experiment-3`. Both projects declare `dev`, `build`, `lint`, and `preview` scripts. No backend service is included in this repository.
